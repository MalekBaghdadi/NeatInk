# Handwriting recognition assets

Provenance and licences only; this file is not bundled into the app.

| File | What | Licence |
|---|---|---|
| `model.onnx` | PP-OCRv5 English mobile text recogniser (PaddleOCR), 7.8 MB. Source: https://huggingface.co/PaddlePaddle/en_PP-OCRv5_mobile_rec_onnx (`inference.onnx`, unchanged). | Apache-2.0, (c) PaddlePaddle Authors |
| `charset.json` | Class table of the model: index 0 = CTC blank (`""`), 1..436 = the `character_dict` of the model's `inference.yml` in order (digits, A-Z, a-z, punctuation, symbols), 437 = space. Generated by `docs/htr_bench/make_charset.py`. | Apache-2.0 (data of the model) |
| `word_freq.txt` | First 50,000 entries of SymSpell's `en-80k` frequency dictionary (lowercase letters and apostrophes only). Counts derive from Google Books Ngrams. | MIT (SymSpell), CC BY 3.0 (Ngrams) |
| `subject_words.txt` | Study vocabulary (neuroscience, psychology, biology, physics, chemistry, statistics, acronyms) with fixed counts, merged into the word list at load time. Generated by `docs/htr_bench/make_subject_words.py`. | Written for this project (no third-party data) |

Model facts (verified with onnxruntime, see `docs/htr-model-notes.md`):

* input `x`, float32 `[N, 3, 48, W]` (N and W dynamic), pixels `(v / 255 - 0.5) / 0.5`
* output float32 `[N, T, 438]` softmax probabilities (not log), T is about W / 8
* class 0 = CTC blank, class i = `character_dict[i - 1]`, class 437 = space

Credits are shown on the in-app licences page (`lib/recognition/recognition_licenses.dart`).
